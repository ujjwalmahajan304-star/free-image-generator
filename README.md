# Free Image Generator v2

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Create a Hugging Face access token with Inference Providers permission.
4. Set `HF_TOKEN` as an environment variable. Never put it in `public/index.html`.
5. Run `npm start`.
6. Open http://localhost:3000

The app supports Text-to-Image and Image-to-Image. Generation uses Hugging Face Inference Providers.
